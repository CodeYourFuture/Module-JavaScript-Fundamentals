What is the purpose of a README file?

A README file explains what a project is, what it does, and why it exists. It provides instructions for installing, using, and configuring the project. It guides contributors on how to help, and includes credits and licensing info.

What is the purpose of a wireframe?

A wireframe is a simple visual layout of a webpage or app that shows structure without design details. It focuses on placement of elements like buttons, menus, and content. It’s used to plan functionality and user flow before adding colors, styles, or graphics.

What is a branch in Git?

A branch in Git is a separate line of development within a repository. It lets you work on features or fixes without affecting the main codebase. Branches can later be merged back into the main project.
