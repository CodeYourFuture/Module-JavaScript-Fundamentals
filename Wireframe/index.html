Wireframe

A wireframe outlines the structure of your page or mobile app. It helps designers figure out where certain elements should live and how the overall design will look.

A brief about README file

A README file is a text file (often named README.md if written in Markdown) that gives an overview of a project. Its main purpose is to explain what the project is, how it works, and how others can use or contribute to it.

Purpose of WIREFRAME

A wireframe is a simple, low-fidelity visual guide that outlines the structure and layout of a webpage, app, or digital product—without focusing on design details like colors, fonts, or images.

Branch in GIT

In Git, a branch is like a separate line of development within a project’s repository. It allows you to: Work independently on new features, bug fixes, or experiments without affecting the main codebase. Keep the main branch (usually main or master) stable, while development happens on other branches. Collaborate with others by creating branches for specific tasks, then later merging them back into the main branch.
