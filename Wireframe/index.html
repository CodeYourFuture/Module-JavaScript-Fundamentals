What is a README file?

A README file is the first point of reference for a project. It explains the project’s purpose, how to install and use it, and how others can contribute. This makes it easier for developers and users to understand and collaborate on the project.

What is a Wireframe?

A wireframe is a simple visual guide that represents the structure of a webpage or app. It helps designers and developers focus on layout and functionality before adding design elements.

What is a Branch in Git?

A branch in Git allows developers to work on features, bug fixes, or experiments without affecting the main project. Once tested, branches can be merged back into the main codebase safely.
