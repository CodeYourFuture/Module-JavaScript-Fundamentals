What is the purpose of a README file?

A README file provides essential information about a project, including its purpose, how to install and use it, and any other relevant details. It serves as documentation for developers and users, typically including instructions, examples, and information about dependencies.

What is the purpose of a wireframe?

A wireframe is a visual guide that represents the skeletal framework of a website. It focuses on layout, content placement, and functionality without design elements, helping teams align on structure before development. Wireframes are essential for planning user experience and interface design.

What is a branch in Git?

In Git, a branch is a separate line of development that allows you to work on new features or fixes without affecting the main codebase. Branches can be merged back into the main branch when complete. This enables parallel development and experimentation while maintaining code stability.
