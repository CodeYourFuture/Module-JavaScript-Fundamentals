Key Concepts

What is the purpose of a README file?

A README is the first document in a repository that explains what the project does, how to set it up, how to use it, and any other notes contributors or users need.

What is the purpose of a wireframe?

A wireframe is a low-fidelity layout showing where content and UI elements go. It helps plan structure before coding.

Learn about wireframes — opens in a new tab

What is a branch in Git?

A Git branch is an independent line of development. Use branches to build features or fixes safely without impacting main.
