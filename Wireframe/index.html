What is Wireframe and its purpose?

A Wireframe is a simple, low-fidelity visual guide that shows the structure and layout of a webpage before it is built with code and design. Its purpose is to act as a plan or blueprint for a webpage or app before it is fully designed or coded.

What is a Git Branch?

A Git Branch is a copy of the project where you can make changes without breaking the main version. Developers use branches to try new ideas, fix bugs, or add features.
