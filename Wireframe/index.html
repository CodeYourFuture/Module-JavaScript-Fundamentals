Development Basics

What is the purpose of a README file?

A README file explains what a project is, how to set it up, and how to use it. It’s the first thing people see when they open a repository, and it provides essential information for users and contributors.

What is the purpose of a wireframe?

A wireframe is a simple visual guide that shows the layout and structure of a webpage or application. Its purpose is to plan the design and user experience before adding details like colours, images, or content.
