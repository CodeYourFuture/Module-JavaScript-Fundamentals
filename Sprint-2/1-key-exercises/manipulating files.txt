String Methods

========================================
1. STRING METHODS
========================================

Purpose:
Manipulate path strings manually.

Example Path:

/Users/rawan/project/file.txt


slice()

Purpose:
Extract part of a string.

Example:
filePath.slice(7)


split()

Purpose:
Break a string into pieces.

Example:
filePath.split("/")

Result:
["", "Users", "rawan", "project", "file.txt"]


includes()

Purpose:
Check if text exists.

Example:
filePath.includes("rawan")


startsWith()

Purpose:
Check beginning of string.

Example:
filePath.startsWith("/Users")


endsWith()

Purpose:
Check ending of string.

Example:
filePath.endsWith(".txt")


indexOf()

Purpose:
Find first occurrence.

Example:
filePath.indexOf("/")


lastIndexOf()

Purpose:
Find last occurrence.

Example:
filePath.lastIndexOf("/")


replace()

Purpose:
Replace text.

Example:
filePath.replace(".txt", ".pdf")


substring()

Purpose:
Extract part of a string.

Example:
filePath.substring(7, 12)


trim()

Purpose:
Remove whitespace.

Example:
filePath.trim()



========================================
2. PATH MODULE
========================================

Import:

const path = require("path");

Purpose:
Manipulate file paths safely.


path.basename()

Purpose:
Get filename.

Example:

path.basename("/Users/rawan/file.txt")

Result:

file.txt


path.dirname()

Purpose:
Get directory path.

Example:

path.dirname("/Users/rawan/file.txt")

Result:

/Users/rawan


path.extname()

Purpose:
Get extension.

Example:

path.extname("file.txt")

Result:

.txt


path.join()

Purpose:
Join path pieces.

Example:

path.join("users", "rawan)
